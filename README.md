# h266ffmpegcovert

A PowerShell and Shell script utility for converting video files to H.266 format using FFmpeg.

## Description

This project provides automated scripts to convert video files to H.266 (HEVC) video codec format using FFmpeg. It includes both PowerShell and Shell implementations for cross-platform compatibility.

## Features

- Video conversion to H.266 format
- Batch processing capabilities
- Cross-platform support (PowerShell and Shell scripts)
- FFmpeg integration

## Requirements

- FFmpeg installed and added to system PATH
- PowerShell (for PowerShell scripts) or Bash (for Shell scripts)

## Installation

1. Clone this repository:
```bash
git clone https://github.com/ElectroDanceWorld-Radio/h266ffmpegcovert.git
```

2. Navigate to the project directory:
```bash
cd h266ffmpegcovert
```

3. Ensure FFmpeg is installed on your system

## Usage

### PowerShell
```powershell
# Run the PowerShell script
.\convert.ps1 -InputFile "video.mp4"
```

### Shell/Bash
```bash
# Run the Shell script
./convert.sh -i video.mp4
```
